# Repo-wide agent instructions

For roasting, reviewing, critiquing, auditing, or scoring a design (UI/UX of web, mobile, desktop apps, dashboards; images such as posters, banners, thumbnails, logos; video or motion), read `skills/design-roast/SKILL.md` and apply it. Do not force the skill for unrelated coding tasks. Only judge what you can actually see: mark anything not visible (animation, other screen sizes, audio) as "tidak dinilai" instead of guessing. Every criticism needs a specific location and a concrete fix.
